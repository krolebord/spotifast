Spotifast Soloist 0.14.2-soloist.2 makes pairing Soloist with your Spotify account much easier. Turning Soloist on opens a short guide that follows the pairing as it happens, works from Spotify's app on your phone or on this computer, explains what to check when Soloist does not show up, and lets you unpair it to start again. Soloist also stops when you quit on macOS, a dropped connection to Spotify is noticed within seconds, and Linux says which library Soloist is missing.

These are the platforms Spotify publishes Soloist for. Intel Macs and Windows on ARM get no build of their own. On an ARM PC, the Windows installer runs under emulation, Soloist included.

## Before you install

- **macOS:** the app is not notarized. After dragging it to Applications, Control-click it and choose Open the first time. If macOS says it is damaged, run `xattr -dr com.apple.quarantine "/Applications/Spotifast Soloist.app"`.
- **Windows:** the installer is not signed, so SmartScreen may warn. Choose More info, then Run anyway.
- **Linux:** unpack the archive and run `spotifast-soloist`. To get a menu entry, copy `spotifast-soloist.desktop` to `~/.local/share/applications/` and `spotifast-soloist.svg` to `~/.local/share/icons/hicolor/scalable/apps/`. Soloist may need a system library your distribution does not install by default; if Settings says "Soloist does not run on this computer", install the library it names (for example `libatomic1`) and try again.
- **Updating from 0.14.2-soloist.1:** quit Spotifast Soloist and install this version over it. Your settings, sign-in and pairing stay.
- **No automatic updates.** Spotifast Soloist never checks for or installs updates. New versions are on [the releases page](https://github.com/krolebord/spotifast-soloist/releases).
- **Installs beside Spotifast.** Settings and the sign-in are kept apart from upstream Spotifast, so a first install signs in once more.

## New

- **A pairing guide.** Turning on Use Soloist before it is paired opens a dialog with the steps: open Spotify's app on your phone or on this computer, signed in to the same account, tap the devices button and choose Soloist. It shows when it is waiting and when it is paired. Pair… in Settings opens it again.
- **Help when Soloist does not show up.** Don't see it? suggests the easiest way, Spotify's desktop app on this computer, then what usually stands in the way: different or guest Wi-Fi, a firewall blocking mDNS, Windows Firewall's question about Soloist, and on macOS the Local Network permission.
- **Unpair Soloist** from Settings, to forget its account and pair it again, for example with another Spotify account.
- **Playing before pairing says what to do.** Instead of appearing to start, playback shows where to pair Soloist.
- **The Soloist settings follow the setup order:** the program, then the API key, then the switch, which says what Soloist needs next.
- **A Soloist that cannot run says why.** When Linux lacks a library Soloist needs, or its C library is too old, Settings shows the system's own message instead of calling the download "not a Soloist build".

## Fixed

- **Soloist stops when you quit Spotifast on macOS,** with Cmd+Q, the Dock's Quit or logging out, instead of playing on with Spotifast gone. A start given up partway no longer leaves a Soloist behind.
- **A dropped connection to Spotify is noticed within seconds** while Soloist plays, instead of up to an hour later, and an idle Spotifast no longer keeps working in the background after a playback engine stops. While waiting for pairing, it asks Soloist about its sign-in less often.
- **Visualizers stay hidden while Soloist plays,** since Soloist's audio never passes through Spotifast. Their settings are kept, and asking for MilkDrop says why it is not available.

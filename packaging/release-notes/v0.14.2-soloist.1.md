Spotifast Soloist 0.14.2-soloist.1 is the first release of this fork: Spotifast 0.14.2 that can play through Spotify Soloist, Spotify's own player, as well as librespot. It installs and runs beside upstream Spotifast, with its own settings and sign-in, so you can keep both.

These are the platforms Spotify publishes Soloist for. Intel Macs and Windows on ARM get no build of their own. On an ARM PC, the Windows installer runs under emulation, Soloist included.

## Before you install

- **macOS:** the app is not notarized. After dragging it to Applications, Control-click it and choose Open the first time. If macOS says it is damaged, run `xattr -dr com.apple.quarantine "/Applications/Spotifast Soloist.app"`.
- **Windows:** the installer is not signed, so SmartScreen may warn. Choose More info, then Run anyway.
- **Linux:** unpack the archive and run `spotifast-soloist`. To get a menu entry, copy `spotifast-soloist.desktop` to `~/.local/share/applications/` and `spotifast-soloist.svg` to `~/.local/share/icons/hicolor/scalable/apps/`.
- **No automatic updates.** Spotifast Soloist never checks for or installs updates. New versions are on [the releases page](https://github.com/krolebord/spotifast/releases).
- **Starts fresh.** Settings and the sign-in are kept apart from upstream Spotifast, so you sign in once more.

## New

- **Play through Spotify Soloist.** Turn on Settings > Spotify Soloist > Use Soloist, download Soloist from Spotify with one click, and add an API key from the [Spotify for Developers dashboard](https://developer.spotify.com/dashboard). Then choose "Spotifast (soloist)" once in the Spotify app on your phone, on the same Wi-Fi, to pair it. Spotifast never redistributes Soloist: it downloads it from Spotify's servers, checks once a day for a newer build, and says when the build has expired. By @krolebord.
- **Soloist plays songs Spotify refuses an audio key for.** When librespot cannot get the key, the message offers Soloist instead. By @krolebord.
- **Soloist follows your choices:** it plays at the chosen audio quality and loudness, takes queue edits, and keeps playing when Spotifast's connection to Spotify drops and returns. Settings that only librespot uses are greyed out while Soloist plays, and hovering says why. By @krolebord.
- **Installs beside Spotifast.** Its own name, folders, saved sign-in, desktop entry, macOS bundle and Windows installer, so both can be installed and run at once. By @krolebord.

## Fixed

- **A playing Liked Songs row stays marked** when rows above it move or the last row moves up. By @krolebord.
- **Loading playback turns Smart Shuffle off,** so the queue is the one you chose. By @krolebord.
